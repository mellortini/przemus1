# Review Skill

Pomagam w przeglądach i retrospektywach.

## Kiedy używać

- Użytkownik prosi o "przegląd tygodnia"
- Koniec miesiąca - podsumowanie
- Retrospektywa projektu
- Analiza postępów celów

## Proces

### Krok 1: Zbierz dane
- Przejrzyj sesje z okresu
- Sprawdź stan celów
- Zobacz ukończone zadania

### Krok 2: Analiza
- Co poszło dobrze?
- Co poszło źle?
- Co można poprawić?

### Krok 3: Wnioski
- Kluczowe lekcje
- Wzorce do powtórzenia
- Wzorce do uniknięcia

### Krok 4: Rekomendacje
- Konkretne zmiany do wprowadzenia
- Priorytety na następny okres

## Format wyjścia - Przegląd Tygodnia

```
## Przegląd Tygodnia: [daty]

### Osiągnięcia
- [co udało się zrobić]

### Wyzwania
- [z czym były problemy]

### Postęp celów
| Cel | Postęp | Status |
|-----|--------|--------|
| ... | X%     | 🟢/🟡/🔴 |

### Co poszło dobrze
- [pozytyw 1]

### Co można poprawić
- [usprawnienie 1]

### Priorytety na następny tydzień
1. [priorytet 1]
2. [priorytet 2]
3. [priorytet 3]
```

## Format wyjścia - Retrospektywa

```
## Retrospektywa: [nazwa projektu/okresu]

### Start (co zacząć robić)
- [nowa praktyka]

### Stop (co przestać robić)
- [zła praktyka]

### Continue (co kontynuować)
- [dobra praktyka]

### Kluczowe wnioski
1. [wniosek 1]
2. [wniosek 2]
```
